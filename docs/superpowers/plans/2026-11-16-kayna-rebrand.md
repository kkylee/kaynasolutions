# Kayna Digital Solutions Rebrand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the site from Sol Digital to Kayna Digital Solutions, replace the old S link mark with an interlocking K mark, and regenerate the brand, favicon, and Open Graph assets.

**Architecture:** The brand name and URL stay centralized in `src/data/site.js`; page metadata stays in `src/data/pages.js`; the header/footer wordmark is the `Wordmark` component. Brand SVGs and PNGs are generated by a committed Node script using the self-hosted Manrope variable font, so the assets remain reproducible.

**Tech Stack:** Vue 3, Vite 8, Tailwind CSS v4, Vitest, sharp, Fontsource Manrope.

**Spec:** `docs/superpowers/specs/2026-11-16-kayna-rebrand-design.md`

## Global Constraints

- Full name: **Kayna Digital Solutions**. Short name: **Kayna**.
- Domain: `https://kaynasolutions.com` — documented placeholder until the real domain is confirmed.
- Keep the existing tagline, positioning, contact details, palette, page structure, and demonstration labels.
- Page titles must be 15–65 characters; meta descriptions 50–160 characters.
- No invented clients, history, awards, certifications, team size, or partnerships.
- Node 22 or newer.
- Do not claim `kaynasolutions.com` is owned or live.

## Review Focus

- The header must not overflow at 320 px; the “Digital Solutions” descriptor hides below `sm`.
- Every page title must stay within the 65-character build limit.
- No visible “Sol” or “Sol Digital” text may remain in current site copy or metadata.
- The favicon and OG image must use the new K mark, not the old S mark.
- Existing contact-detail and demonstration tests must keep passing.
